# ルミナ・スパーク

ピンク髪の少女ルミナが、星空の発電都市を駆け抜けるオリジナル横スクロールアクション。GPTImageで主人公・敵・ボス・背景を生成した、1ステージ完結のWindowsゲームです。

## 遊び方

**このフォルダーの `起動.cmd` をダブルクリック**してください。インストール・インターネット・ブラウザーは不要です。Enterまたは「出撃する」で開始します。フォルダーごと移動しても起動できます。実行環境は `runtime/Godot.exe` を同梱しています。

- 移動：← → / A D
- ジャンプ：Z / Space（空中でもう一度押すと二段ジャンプ）
- 足場を降りる：↓ / S ＋ Z / Space（パッド：下＋A）
- 射撃：X / J（押すたびに1発。連打で連射）
- ため撃ち：射撃ボタンを長押しして離す。0.8秒で溜め撃ち、1.6秒で金色の最大溜め（敵を貫通）。溜め中はゆっくり歩く。V / パッドYも同じボタン
- セーバー：K / パッドRB。EN（体力の下の金色ゲージ）を35使う。前方の敵弾を消し、敵へ近接攻撃。振り始めのほんの一瞬に当てた弾だけ跳ね返り、ENが8戻る。再使用0.75秒。ENは時間でゆっくり回復（毎秒6）。オレンジのトゲ弾・盾・レーザーは消せない
- ジャストダッシュ：ダッシュ中に敵弾をくぐるとENが6回復
- ダッシュ：Shift / C（短時間無敵。再使用まで0.7秒）
- 一時停止：Esc、再開：Esc / Enter
- 音の切り替え：M、全画面：F11、終了：ウィンドウの×
- タイトルでE / パッドY・上下：アシスト難易度。体力増加・敵弾の減速・被ダメージ軽減。

ゲームパッド：左スティック / 十字キーで移動、Aでジャンプ（タイトル・やられた画面では決定）、Xで射撃（長押しでため）、Yも射撃、Bでダッシュ、RBでセーバー、Startで開始・一時停止・再開。ポーズ中のBackでタイトルへ戻ります。Xbox配置基準。実機パッドでの動作は未確認です。

## ステージ

24区画・6エリアを進み、最後に星炉の守護者「ASTER GUARDIAN」と戦います。各エリアの終端にはスターコアと、向こうが見えず弾も通らない扉があります。壁の上部と枠を残し、下の通路だけが開きます。体全体が抜けると後ろの扉が閉じて再ロックされ、前のエリアには戻れません。抜け切る前なら引き返せます。死亡・落下からの再開も通過後の側になります。閉じた壁は弾・セーバー・敵も遮ります。扉の開け方はエリアごとに違います：コアを12秒同期して区画の敵を全滅（01・05）、光るスイッチを撃つ（02・06）、コア回収後の待ち伏せを全滅（03）、ため撃ちで通路のロックを破壊（04）。

足場は下から通り抜けられます。大きな段差は二段ジャンプで越えます。穴に落ちると体力が3減り（アシストは2）、直前の足場に戻ります。ピンクの床レーザーは「注意」の表示後に点灯します。回復クリスタルは体力が減っているときだけ回収します。各エリア入口とボス直前で自動チェックポイント・全回復。残機制限はありません。再開時は倒した道中の敵と回収済みコアを維持し、ボスの体力は戻ります。アプリを閉じると進行はリセットされます。

初見で約10分のプレイを狙っています。人による通しプレイ時間は未計測です。被ダメージを無効化した経路検査は約3分16秒で65体・6コア・ボスをクリアしています。プレイ時間は操作習熟度やリトライで変わります。

## 改良版の特徴（2026-10-24）

6エリアを個別に配置しました。エリアごとに大きな仕掛けがあります。配電回廊はレーザーと、予告のあと床全体に流れる電流（足場へ逃げる）。空中搬送路は動く足場と、左右交互に吹く突風。冷却プラントはほとんど止まれない氷の床。防衛区画は盾と砲台、サーチライト（見つかると周りの敵が一斉に撃つ）。コアへの道は低重力（高く跳べ、ゆっくり落ちる）と縦登りです。ドローンはランダムに飛び回ります。盾は溜め撃ちで破壊できます。敵の位置は遊ぶたびにずれ、3割ほどはそのエリアまでに出た同じ系統の別の敵に入れ替わります。敵は種類ごとに攻撃を使い分けます：甲虫と車輪ロボは点滅のあと突進、ドローンは単発と3連射、盾ロボは狙い撃ちと床を走るトゲ弾、砲台は3方向弾と紫の追尾弾、爆撃機は床で左右に割れる爆弾。ボスは追尾弾、トゲ弾が混ざった全方位弾なども使います。

ボスは登場演出後に左右へ移動し、体力半分で第2形態へ変化します。空からのレーザーは縦線と三角の予告を見て避け、突進にはジャンプやダッシュを使ってください。撃破後は約2.6秒の爆発演出を経てクリアします。死亡時は第1形態・全体力から再戦します。

歩行はGPTImageの共通パーツを使い、8つの基準姿勢の間を補間します。右脚と左脚が支持脚・遊脚を交代し、接地した足は移動量に合わせて後ろへ流れます。靴底の接地と脚の長さを固定し、溜め歩きも同じ周期をゆっくり再生します。各モーションの倍率は、曲げた脚や光を含む画像全体ではなく頭の寸法を基準に揃えました。移動中の上体は最大20度前に傾き、肩を支点に両腕を脚と逆向きへ振ります。銃は左手で、脚と胴体より奥の最背面に描きます。射撃・溜め入力中と最後の発射から0.25秒間は銃の腕を水平に前へ向けます。各ポーズの銃口から弾と発射光が出ます。セーバーは地上6コマと、両膝を畳んだ空中専用6コマを使い分けます。ジャンプ＋Kの同時入力、地上攻撃中のジャンプにも対応し、空中で始めた一振りは着地しても同じモーションを最後まで再生します。1振りにつき同じ敵には1回だけ当たります。

主人公を104pxへ拡大し、被弾・チャージ・ダッシュ・勝利のポーズ、残像、ノックバック、撃破ヒットストップ、爆発・弾のアニメーションを追加しました。金色の星がコア、青緑の結晶が回復です。回復は満タン時に暗く表示されます。

ステージ配置の本体は `data/level.json`。検査もこのファイルのジャンプ範囲と登り順を読みます。画像は `assets/regions.json` に記録した不透明領域で切り出します。

## 制作・検証

Godot 4.7.2 / GDScript。画像は組み込みGPTImage、BGM・効果音はオリジナルのプログラム合成です。画像のプロンプトは `assets/PROMPTS.md`、`assets/PROMPTS-v2.md`、`assets/motion/PROMPTS-rig.md`、`assets/motion/PROMPTS-arms-air.md` に保存しています。

`powershell -ExecutionPolicy Bypass -File tools/verify.ps1` で読み込み・操作・経路検査を実行できます。`-Capture` を加えるとネイティブゲーム画面15枚とモーション・体格比較・補間確認用127枚を `test-output/` に保存します。ブラウザーは使用しません。

検査結果の要約は `検証結果.md`、引き継ぎは `HANDOFF.md`。描画はNVIDIA GeForce RTX 4060 / OpenGL 3.3で確認しました。人の手による難易度調整、ゲームパッド実機、別PC、音の聴感チェックは未実施です。
