# ルミナ・スパーク

ピンク髪の少女ルミナが、星空の発電都市を駆け抜けるオリジナル横スクロールアクション。GPTImageで主人公・敵・ボス・背景を生成した、1ステージ完結のWindowsゲームです。

## 遊び方

**このフォルダーの `起動.cmd` をダブルクリック**してください。インストール・インターネット・ブラウザーは不要です。Enterまたは「出撃する」で開始します。フォルダーごと移動しても起動できます。実行環境は `runtime/Godot.exe` を同梱しています。

- 移動：← → / A D
- ジャンプ：Z / Space（空中でもう一度押すと二段ジャンプ）
- 射撃：X / J（押し続けると連射）
- チャージ：Vを0.8秒以上押して離す
- ダッシュ：Shift / C（短時間無敵。再使用まで0.7秒）
- 一時停止：Esc、再開：Esc / Enter
- 音の切り替え：M、全画面：F11、終了：ウィンドウの×
- タイトルでE：アシスト難易度。体力増加・敵弾の減速・被ダメージ軽減。

ゲームパッド：左スティック / 十字キーで移動、Aでジャンプ（タイトル・やられた画面では決定）、Xで射撃、Yでチャージ、Bでダッシュ、Startで開始・一時停止・再開。Xbox配置基準。実機パッドでの動作は未確認です。

## ステージ

24区画・6エリアを進み、最後に星炉の守護者「ASTER GUARDIAN」と戦います。各エリアの終端では足場上の金色のリングが付いたスターコアを回収してください。18秒間の同期中に増援が出現します。同期完了と、その区画の敵の全撃破でゲートが開きます。

足場は下から通り抜けられます。大きな段差は二段ジャンプで越えます。穴に落ちると体力が3減り（アシストは2）、直前の足場に戻ります。ピンクの床レーザーは「注意」の表示後に点灯します。回復クリスタルは体力が減っているときだけ回収します。各エリア入口とボス直前で自動チェックポイント・全回復。残機制限はありません。再開時は倒した道中の敵と回収済みコアを維持し、ボスの体力は戻ります。アプリを閉じると進行はリセットされます。

初見で約10分のプレイを狙っています。人による通しプレイ時間は未計測です。被ダメージを無効化した経路検査は約3分30秒で全85体・6コア・ボスをクリアしています。プレイ時間は操作習熟度やリトライで変わります。

## 制作・検証

Godot 4.7.2 / GDScript。画像は組み込みGPTImage、BGM・効果音はオリジナルのプログラム合成です。画像のプロンプトは `assets/PROMPTS.md` に保存しています。

`powershell -ExecutionPolicy Bypass -File tools/verify.ps1` で読み込み・操作・経路検査を実行できます。`-Capture` を加えるとネイティブゲーム画面4枚を `test-output/` に保存します。ブラウザーは使用しません。

検査結果の要約は `検証結果.md`、引き継ぎは `HANDOFF.md`。描画はNVIDIA GeForce RTX 4060 / OpenGL 3.3で確認しました。人の手による難易度調整、ゲームパッド実機、別PC、音の聴感チェックは未実施です。
