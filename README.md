# LUMINA SPARK — 星炉のリベリオン —

ピンク髪の少女ルミナが、空中都市・地上・地下施設を駆け抜けるオリジナル2Dアクション。GPTImageで主人公・敵・ボス・背景を生成した、全3ステージのWindowsゲームです。

タイトル画面はGPTImageの専用一枚イラストと透過ロゴを使用。夜の発電都市と金色の星炉を背にしたルミナを右側へ、ロゴ・副題・出撃メニューを左側へ配置しています。タイトル専用素材と生成プロンプトは `assets/title/` に保存しています。

## 遊び方

[Windows版をダウンロード（GitHub Releases）](https://github.com/shinnuga-crypto/lumina-spark/releases/latest)

**配布版は `LuminaSpark.exe` をダブルクリック**してください。画像とBGMをEXEに内蔵しており、単体で起動します。インストール・Godot・インターネット・ブラウザーは不要です。Windows 10/11 x64、OpenGL 3.3対応環境向け。Enterまたは「出撃する」で開始します。ZIP版には同じEXEと遊び方、Godotのライセンス表示を同梱します。

開発フォルダーでは `起動.cmd` からも起動できます（`runtime/Godot.exe` が必要）。GitHubのソースにはGodot本体を含めません。

タイトルで **1 / 2 / 3**（パッドの十字左右、またはステージ表示をクリック）で各ステージを直接選べます。クリア後にEnterで次へ進み、ステージ3のクリア後はタイトルへ戻ります。スコアとランクは各ステージで集計し、最高スコアは全ステージ・難易度共通です。

- 移動：← → / A D
- ジャンプ：Z / Space（空中でもう一度押すと二段ジャンプ）
- 急降下：低重力エリアの空中で ↓ / S / パッド下
- 足場を降りる：↓ / S ＋ Z / Space（パッド：十字下またはスティック下＋A）。地面の上では普通のジャンプ
- 射撃：X / J / マウス左 / パッドRT（押すたびに1発。連打で連射）
- 射撃方向：↑ / W、↓ / Sと左右を組み合わせて8方向。マウスの左か右を押すとマウス照準へ切り替わり、任意の角度に狙える（キーボード操作で解除）。パッドは右スティックで全方向、左スティックで移動。左手の銃腕を肩と肘のボーンで回し、銃口・弾・発射光・ための光が同じ位置と方向を使う
- ため撃ち：射撃ボタンを長押しして離す。0.8秒で溜め撃ち、1.6秒で金色の最大溜め（敵を貫通）。溜め中はゆっくり歩く。V / パッドYも同じボタン。ためたままセーバーを振れる。振っている途中で離したため撃ちは、振り終わりに出る
- セーバー：K / パッドRB。ゲージなし、再使用0.85秒。ジャストでない受け止めは1発ごとに再使用が0.2秒延びる（最大1.4秒）。前方の敵弾を消し、敵へ近接攻撃。振り始めのほんの一瞬に当てた弾だけ跳ね返り、いちばん近い敵（ボス）を追いかける反射弾になる。オレンジのトゲ弾・盾・レーザーは消せない
- ジャストダッシュ：ダッシュ中に敵弾をくぐると、次の1発がMAXため撃ち（3秒以内）、セーバーとダッシュがすぐ使える、0.35秒だけ半分の速さになる（スローは1.5秒に1回まで）
- ダッシュ：Shift / C（0.24秒無敵。再使用まで0.45秒）
- 一時停止：Esc、再開：Esc / Enter
- 設定：タイトルかポーズ中に O（パッド：タイトルでBack、ポーズ中にY）。BGMと効果音の音量（0〜10）、キーボードとパッドのボタン割り当て（パッドの方向は十字キーとスティックで固定、LT/RTも割り当て可）。user://settings.cfg に保存
- 音の切り替え：M、全画面：F11、終了：ウィンドウの×
- タイトルでE / パッドY・上下：難易度をノーマル → アシスト → 弾幕 → 鬼弾幕の順に切り替え。アシストは体力増加・敵弾の減速・被ダメージ軽減。弾幕は敵の弾が5倍（角度と速さがばらけた広い扇状、床を走る弾は5つのばらけた速さ）、被弾1ダメージ、セーバーの出が速く再使用0.22秒、ダッシュ中にも振れる、ジャスト受付が長い、反射弾の威力1。鬼弾幕は弾幕のルールで敵の弾が10倍、およそ3発に1発がセーバーで消せないオレンジのトゲ弾。

ゲームパッド：左スティック / 十字キーで移動、Aでジャンプ（タイトル・やられた画面では決定）、Xで射撃（長押しでため）、Yも射撃、Bでダッシュ、RBでセーバー、Startで開始・一時停止・再開。ポーズ中のBackでタイトルへ戻ります。Xbox配置基準。最後に触った機器（キーボードかパッド）に合わせて、画面の操作説明が切り替わります。実機パッドでの動作は未確認です。

## ステージ

ステージ1「空中都市」は従来の24区画・6エリアを進み、最後に星炉の守護者「ASTER GUARDIAN」と戦います。各エリアの終端にはスターコアと、向こうが見えず弾も通らない扉があります。壁の上部と枠を残し、下の通路だけが開きます。体全体が抜けると後ろの扉が閉じて再ロックされ、前のエリアには戻れません。抜け切る前なら引き返せます。死亡・落下からの再開も通過後の側になります。閉じた壁は弾・セーバー・敵も遮ります。扉の開け方はエリアごとに違います：コアを12秒同期して区画の敵を全滅（01・05）、光るスイッチを撃つ（02・06）、コア回収後に搬送路の番人を撃破（03）、ため撃ちで通路のロックを破壊（04）。

ステージ2「地上・夜明けの迎撃線」は横11,280pxの地上戦。空からの迎撃機・機雷母艦・機械コウモリが多く出現します。青い跳躍台は空中へ打ち上げ、搬送ベルトは足元を流します。予告付き空爆は防空シェルターの屋根の下で防げます。最後は飛行ボス「SKY VULTURE」。扇状射撃、機雷投下、予告後の急降下を避け、上空へ撃ち返してください。

ステージ3「地下・星骸の深淵」は縦6,380pxを降りる施設。縦方向に追うカメラを使います。3か所の中央隔壁は下向き射撃で壊し、ヒビの足場は着地から0.65秒で崩れます。圧搾機は予告範囲から退避してください。薄い足場は深さに関係なく下＋ジャンプで降りられます。最奥の「ABYSS MOTHER」は壁に固定された巨大要塞。2つの封印装置を破壊するとコアが周期的に開きます。水平砲撃と扇状弾を避け、露出した目のコアを上へ狙って撃ち込みます。死亡後の再戦では封印装置とボス体力が戻ります。

足場は下から通り抜けられます。大きな段差は二段ジャンプで越えます。穴に落ちると体力が3減り（アシストは2）、直前の足場に戻ります。ピンクの床レーザーは「注意」の表示後に点灯します。回復クリスタルは体力が減っているときだけ回収します。各エリア入口とボス直前で自動チェックポイント・全回復。残機制限はありません。再開時は倒した道中の敵と回収済みコアを維持し、ボスの体力は戻ります。アプリを閉じると進行はリセットされます。自己ベストのスコアは保存されます。

ステージ1は初見で約10分のプレイを狙っています。全3ステージとも人による通しプレイ時間と難易度は未計測です。経路検査では被ダメージを無効化して、移動・射撃の実入力でボスまでの到達性を確認しています。プレイ時間は操作習熟度やリトライで変わります。

## 改良版の特徴（2026-10-24）

6エリアを個別に配置しました。エリアごとに大きな仕掛けがあります。配電回廊はレーザーと、予告のあと床全体に流れる電流（足場へ逃げる）。空中搬送路は動く足場と、左右交互に吹く突風。冷却プラントはほとんど止まれない氷の床。防衛区画は盾と砲台、サーチライト（見つかると周りの敵が一斉に撃つ）。コアへの道は低重力（空中で止まりにくい慣性、周期的な天井の帯電、↓で急降下）と縦登りです。ドローンはランダムに飛び回ります。盾は溜め撃ちで破壊できます。敵の位置は遊ぶたびにずれ、3割ほどはそのエリアまでに出た同じ系統の別の敵に入れ替わります。敵は種類ごとに攻撃を使い分けます：甲虫と車輪ロボは点滅のあと突進、ドローンは単発と3連射、盾ロボは狙い撃ちと床を走るトゲ弾、砲台は3方向弾と紫の追尾弾、爆撃機は床で左右に割れる爆弾。ボスは追尾弾、トゲ弾が混ざった全方位弾なども使います。

ボスは登場演出後に左右へ移動し、体力半分で第2形態へ変化します。空からのレーザーは縦線と三角の予告を見て避け、突進にはジャンプやダッシュを使ってください。撃破後は約2.6秒の爆発演出を経てクリアします。死亡時は第1形態・全体力から再戦します。

歩行はGPTImageの共通パーツを使い、8つの基準姿勢の間を補間します。右脚と左脚が支持脚・遊脚を交代し、接地した足は移動量に合わせて後ろへ流れます。靴底の接地と脚の長さを固定し、溜め歩きも同じ周期をゆっくり再生します。各モーションの倍率は、曲げた脚や光を含む画像全体ではなく頭の寸法を基準に揃えました。移動中の上体は最大20度前に傾き、肩を支点に両腕を脚と逆向きへ振ります。銃は左手で、脚と胴体より奥の最背面に描きます。射撃・溜め入力中と最後の発射から0.25秒間は、銃腕を指定方向へ向けます。各ポーズの銃口から弾と発射光が出ます。セーバーは地上6コマと、両膝を畳んだ空中専用6コマを使い分けます。ジャンプ＋Kの同時入力、地上攻撃中のジャンプにも対応し、空中で始めた一振りは着地しても同じモーションを最後まで再生します。1振りにつき同じ敵には1回だけ当たります。

主人公を104pxへ拡大し、被弾・チャージ・ダッシュ・勝利のポーズ、残像、ノックバック、撃破ヒットストップ、爆発・弾のアニメーションを追加しました。金色の星がコア、青緑の結晶が回復です。回復は満タン時に暗く表示されます。

ステージ1の配置は `data/level.json`、地上と地下は `data/stage2.json` / `data/stage3.json`。追加ステージの描画・敵・ギミック・ボスは `campaign.gd`、共通の操作・銃のボーンは `game.gd`。追加画像は `assets/campaign/`、プロンプトは同フォルダーの `PROMPTS.md`。画像の画素は変更せず測定した不透明領域で切り出します。

## スコアとランク

3秒以内に敵を続けて倒すとコンボがつながり、撃破点が1.0倍から最大2.0倍になります。被弾するとコンボは切れます。ジャスト反射は100点、ジャストダッシュは60点。反射弾がボス系に命中するとダメージが3→6（弾幕・鬼弾幕は1→2）になり、さらに150点と金色の成功演出が入ります。地下ボスの閉じた装甲への命中では加点しません。

通常敵は100〜200点、搬送路の番人は2000点、コアは500点。ノーダメージで区間を抜けると300点。クリアで2000点、通しのノーダメージはさらに1500点。最高スコアはタイトルに表示され、ゲームのユーザーデータへ保存されます（ノーマル・アシスト共通の自己ベスト）。

クリアランクは敵のランダム配置による点数差を抑えるため、被ダメージ・リトライ・時間・最大コンボで判定します。S：リトライ0、被ダメージ6以下、10分以内、最大コンボ3以上。A：リトライ1以下、被ダメージ18以下、13分以内、コンボ2以上。B：リトライ3以下、被ダメージ40以下、16分以内。それ以外はC。アシストはクリア画面にASSISTと表示します。

中盤の空中搬送路の出口には「搬送路の番人」が出現します。オレンジの予告を見て3方向射撃・突進・床衝撃波を避けてください。撃破で出口が開きます。低重力エリアの天井は予告後に帯電します。空中で横方向を早めに切り返し、↓ / S / パッド下の急降下で高度と着地点を調節してください。

## BGM

ユーザー提供の **Heroic Quest.mp3** を道中、**Untitled.mp3** をミニボス・最終ボス戦に使用します。両曲をループし、切替時は0.4秒フェードイン。ミニボス撃破後は道中曲へ戻り、最終ボス撃破時は止まります。MでBGMと効果音を切り替えます。元のMP3は再圧縮せずコピーしています。

## 制作・検証

Windows単体EXEのビルド：Godot 4.7.2と同バージョンのWindows x86_64エクスポートテンプレートを用意し、`powershell -ExecutionPolicy Bypass -File tools/build-windows.ps1 -GodotExe "C:\Godot\Godot.exe"`。出力は `build/windows/LuminaSpark.exe`、配布ZIPは `build/LuminaSpark-v1.1.0-windows-x64.zip`、ハッシュは `build/SHA256SUMS.txt`。ローカルの同梱Godotを使う場合は `-GodotExe` を省略できます。PCK埋め込みと外部DLL不要の設定は `export_presets.cfg` に保存しています。[Windowsエクスポートの公式説明](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_windows.html)。

Godot 4.7.2 / GDScript。画像は組み込みGPTImage、BGMは上記のユーザー提供曲、効果音はオリジナルのプログラム合成です。画像のプロンプトは `assets/PROMPTS.md`、`assets/PROMPTS-v2.md`、`assets/motion/PROMPTS-rig.md`、`assets/motion/PROMPTS-arms-air.md`、`assets/improvements/PROMPTS.md`、`assets/title/PROMPTS.md` に保存しています。

`powershell -ExecutionPolicy Bypass -File tools/verify.ps1` で読み込み・操作・壁扉・改善機能・経路検査を実行できます。`-Capture` を加えるとネイティブゲーム画面52枚（従来26＋追加ステージ・照準26）とモーション・体格比較・補間確認用127枚を `test-output/` に保存します。ブラウザーは使用しません。

検査結果の要約は `検証結果.md`、引き継ぎは `HANDOFF.md`。描画はNVIDIA GeForce RTX 4060 / OpenGL 3.3で確認しました。人の手による難易度調整、ゲームパッド実機、別PC、音の聴感チェックは未実施です。
