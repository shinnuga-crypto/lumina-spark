# ルミナ・スパーク

ピンク髪の少女ルミナが、星空の発電都市を駆け抜けるオリジナル横スクロールアクション。GPTImageで主人公・敵・ボス・背景を生成した、1ステージ完結のWindowsゲームです。

## 遊び方

**このフォルダーの `起動.cmd` をダブルクリック**してください。インストール・インターネット・ブラウザーは不要です。Enterまたは「出撃する」で開始します。フォルダーごと移動しても起動できます。実行環境は `runtime/Godot.exe` を同梱しています。

- 移動：← → / A D
- ジャンプ：Z / Space（空中でもう一度押すと二段ジャンプ）
- 足場を降りる：↓ / S ＋ Z / Space（パッド：下＋A）
- 射撃：X / J（押し続けると連射）
- チャージ：Vを0.8秒以上押して離す
- ダッシュ：Shift / C（短時間無敵。再使用まで0.7秒）
- 一時停止：Esc、再開：Esc / Enter
- 音の切り替え：M、全画面：F11、終了：ウィンドウの×
- タイトルでE / パッドY・上下：アシスト難易度。体力増加・敵弾の減速・被ダメージ軽減。

ゲームパッド：左スティック / 十字キーで移動、Aでジャンプ（タイトル・やられた画面では決定）、Xで射撃、Yでチャージ、Bでダッシュ、Startで開始・一時停止・再開。ポーズ中のBackでタイトルへ戻ります。Xbox配置基準。実機パッドでの動作は未確認です。

## ステージ

24区画・6エリアを進み、最後に星炉の守護者「ASTER GUARDIAN」と戦います。各エリアの終端では足場上の金色のリングが付いたスターコアを回収してください。12秒間の同期中、残り8秒と4秒で増援が出現します。同期完了と、その区画の敵の全撃破でゲートが開きます。

足場は下から通り抜けられます。大きな段差は二段ジャンプで越えます。穴に落ちると体力が3減り（アシストは2）、直前の足場に戻ります。ピンクの床レーザーは「注意」の表示後に点灯します。回復クリスタルは体力が減っているときだけ回収します。各エリア入口とボス直前で自動チェックポイント・全回復。残機制限はありません。再開時は倒した道中の敵と回収済みコアを維持し、ボスの体力は戻ります。アプリを閉じると進行はリセットされます。

初見で約10分のプレイを狙っています。人による通しプレイ時間は未計測です。被ダメージを無効化した経路検査は約3分49秒で全78体・6コア・ボスをクリアしています。プレイ時間は操作習熟度やリトライで変わります。

## 改良版の特徴（2026-10-24）

6エリアを個別に配置しました。配電回廊はレーザー、空中搬送路は動く足場、冷却プラントは滑る床、防衛区画は盾と砲台、終盤は組み合わせと縦登りです。盾はVのチャージ弾で破壊できます。車輪ロボは素早く動き、爆撃機は真下へ弾を落とします。

ボスは登場演出後に左右へ移動し、体力半分で第2形態へ変化します。空からのレーザーは縦線と三角の予告を見て避け、突進にはジャンプやダッシュを使ってください。撃破後は約2.6秒の爆発演出を経てクリアします。死亡時は第1形態・全体力から再戦します。

主人公を104pxへ拡大し、被弾・チャージ・ダッシュ・勝利のポーズ、残像、ノックバック、撃破ヒットストップ、爆発・弾のアニメーションを追加しました。金色の星がコア、青緑の結晶が回復です。回復は満タン時に暗く表示されます。

ステージ配置の本体は `data/level.json`。検査もこのファイルのジャンプ範囲と登り順を読みます。画像は `assets/regions.json` に記録した不透明領域で切り出します。

## 制作・検証

Godot 4.7.2 / GDScript。画像は組み込みGPTImage、BGM・効果音はオリジナルのプログラム合成です。画像のプロンプトは `assets/PROMPTS.md` と `assets/PROMPTS-v2.md` に保存しています。

`powershell -ExecutionPolicy Bypass -File tools/verify.ps1` で読み込み・操作・経路検査を実行できます。`-Capture` を加えるとネイティブゲーム画面9枚を `test-output/` に保存します。ブラウザーは使用しません。

検査結果の要約は `検証結果.md`、引き継ぎは `HANDOFF.md`。描画はNVIDIA GeForce RTX 4060 / OpenGL 3.3で確認しました。人の手による難易度調整、ゲームパッド実機、別PC、音の聴感チェックは未実施です。
