# ユーザー提供BGM

- heroic-quest.mp3：提供された「Heroic Quest.mp3」をそのままコピー。道中で使用（約3分8.6秒）。
- untitled.mp3：提供された「Untitled.mp3」をそのままコピー。搬送路のミニボス・最終ボス戦で使用（約3分11秒）。

元ファイルとSHA-256が一致。再圧縮・切り詰めはしていない。GodotのMP3ループを有効にし、切り替え時に0.4秒フェードイン。BGM音量-18dB。ミニボス撃破後は道中曲へ戻り、最終ボス撃破時は停止する。MはBGM・効果音の音切替。タイトル・クリア画面で音を有効にしてもBGMを再開しない。

以前の合成曲assets/music.wavは履歴として保存されているが、現在は読み込まない。効果音は従来の合成音を継続使用。
